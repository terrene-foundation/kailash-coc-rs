## Instrument notes

1. **The status column was stale by 7×** — 133 of 135 stamps predated the sync (93 of them from
   one bulk pass on 2026-08-09). `ALREADY-SOLVED: 10` was never a post-sync measurement.
2. **The discriminating instrument for ingest** is "modified by the sync commit ⇒ loom owns the
   path", with two controls: `.proposals/` shows 0 lines (a path loom does not own), and the
   delete pass fired 12 times (so "untouched" is distinguishable from "owned").
3. **A lane's own summary miscounted its own table** (6 vs 7 ALREADY-SOLVED). The table was
   used. `instrument-discipline.md` MUST-3(b) — read the hits, not the tally — caught it.
4. **I broke `latest.yaml` once.** The first restamp emitted status values unquoted; several
   carried `: ` inside prose and YAML read them as mappings. Restored from backup, redone with
   mandatory quoting and an in-memory parse check before writing.
5. **A lane's first sweep used an unquoted `for f in $files`** — zsh does not word-split, so it
   ran once on the whole string. Had it been trusted, every entry in that lane would have read
   STILL-OPEN. The lane caught it; recorded because it nearly inverted 15 verdicts.
6. **Sweep 4 was enumerated unfiltered.** `--no-merged` was used only to rank: 8 remote refs, 7
   ranked as unmerged candidates. `pr/87` appears in the ranker but not the remote enumeration —
   a local ref, surfaced rather than silently dropped.
7. **Sweep 5's N/A is honest, not a substituted proxy.** `spec_count=0`, no repo-level spec
   tree, no `sweep-redteam.py` → orchestration-mode. The escalation checker independently
   confirms zero unadjudicated streaks across 18 reports.
